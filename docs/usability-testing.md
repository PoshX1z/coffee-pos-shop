# รายงานผลการทดสอบ Usability Testing (`wk12-usability-testing.md`)

---

## 1. ข้อมูลผู้เข้าร่วมการทดสอบ (Roles & Responsibilities)

- **ผู้ทดสอบ (Participant):** สมาชิกกลุ่มทดสอบ (ทำหน้าที่ปฏิบัติตาม Task และ Think-Aloud)
- **ผู้สังเกตการณ์ (Observer/Note-taker):** สมาชิกกลุ่มทดสอบ (ทำหน้าที่จดบันทึกพฤติกรรมและคำพูด)
- **ผู้จับเวลาและสังเกตเพิ่มเติม (Timekeeper & Assistant):** สมาชิกกลุ่มทดสอบ

---

## 2. รายการโจทย์การทดสอบ (Test Tasks)

### Task 1 (Happy Path: สั่งซื้อเมนูปกติสำเร็จ)

> **สถานการณ์:** มีลูกค้าสั่ง "อเมริกาโน่เย็น หวานน้อย 1 แก้ว"  
> **เป้าหมาย:** เลือกเมนูอเมริกาโน่ ปรับระดับความหวานเป็น 50% เพิ่มลงตะกร้า เลือกชำระเงินด้วยเงินสด และกด "ยืนยันการชำระเงิน" ให้สำเร็จ

### Task 2 (Error Path: จัดการเมนูที่สินค้าในสต็อกหมด)

> **สถานการณ์:** ลูกค้าต้องการสั่ง "ชาไทยเย็น" แต่ในระบบแสดงว่าวัตถุดิบหมด  
> **เป้าหมาย:** ค้นหาเมนูชาไทย ตรวจสอบสถานะสต็อก และทำการเลือกเมนูทดแทน (เช่น "ชาเขียวเย็น") เพิ่มลงตะกร้าแทน

### Task 3 (Order Modification & Cancellation: แก้ไขและยกเลิกรายการ)

> **สถานการณ์:** ลูกค้าเปลี่ยนใจขอเพิ่มจำนวน "เค้กส้ม" จาก 1 ชิ้นเป็น 2 ชิ้น และขอยกเลิกรายการ "ชาเขียวเย็น"  
> **เป้าหมาย:** เข้าไปหน้าตะกร้าสินค้า เพิ่มจำนวนเค้กส้ม ลบรายการชาเขียวเย็นออก แล้วตรวจสอบยอดรวมเงินให้ถูกต้อง

## 4. รายการปัญหาการใช้งาน (Usability Issues) & Severity Rating

### Issue 1: ป้ายเตือน "สินค้าหมด" (Out of Stock) ไม่ชัดเจน

- **องค์ประกอบ 1 (Problem Description):** สถานะสินค้าหมดใช้โทนสีใกล้เคียงกับสินค้าปกติ ผู้ใช้ไม่ทราบทันทีว่ากดสั่งไม่ได้
- **องค์ประกอบ 2 (Location):** หน้าหมวดหมู่สินค้า (Menu Grid View)
- **องค์ประกอบ 3 (Impact/Evidence):** ผู้ทดสอบพยายามคลิกเมนูชาไทย 3-4 ครั้ง นึกว่าระบบค้าง ก่อนจะตระหนักว่าสินค้าหมด (เสียเวลาใน Task 2)
- **องค์ประกอบ 4 (Severity Level):** **Major Issue** (ทำให้เกิดความสับสนและชะงักในการใช้งาน)

### Issue 2: ปุ่มลบรายการในตะกร้าสินค้ามีขนาดเล็กเกินไป

- **องค์ประกอบ 1 (Problem Description):** ไอคอนถังขยะสำหรับลบรายการมีขนาดเล็ก และสีจาง ทำให้สังเกตยาก
- **องค์ประกอบ 2 (Location):** หน้าสรุปรายการสั่งซื้อ (Cart / Order Summary Panel)
- **องค์ประกอบ 3 (Impact/Evidence):** ผู้ทดสอบใช้เวลาเพ่งมองหาปุ่มลบรายการใน Task 3
- **องค์ประกอบ 4 (Severity Level):** **Minor Issue** (ผู้ใช้ยังทำงานสำเร็จได้ แต่ลดความรวดเร็ว)

### Issue 3: ปุ่ม "ชำระเงิน" (Checkout) กลมกลืนกับพื้นหลัง

- **องค์ประกอบ 1 (Problem Description):** สีของปุ่มชำระเงินหลักไม่โดดเด่นเพียงพอเมื่อเทียบกับส่วนอื่นของหน้าจอ
- **องค์ประกอบ 2 (Location):** ด้านล่างสุดของแถบตะกร้าสินค้า
- **องค์ประกอบ 3 (Impact/Evidence):** ผู้ทดสอบกวาดสายตาหาปุ่มชำระเงินใน Task 1 เล็กน้อย
- **องค์ประกอบ 4 (Severity Level):** **Minor Issue**

## 5. การแก้ไขและแผนการปรับปรุง UI (Fixes & Action Plan)

### 1. การแก้ไขทันทีในคาบ (Immediate Fix - Major Issue)

- **ปัญหาที่เลือกแก้ไข:** Issue 1 (ป้ายเตือน "สินค้าหมด" ไม่ชัดเจน)
- **การปรับปรุง UI Real-time:**
  - ปรับสไตล์ของการ์ดสินค้าที่หมดให้เป็น **Greyscale (สีเทา)** และเพิ่ม Overlay โปร่งแสงพร้อมข้อความป้ายกำกับสีแดงเข้ม **"OUT OF STOCK / สินค้าหมด"**
  - ใส่คุณสมบัติ `disabled` ที่ปุ่มเพื่อไม่ให้คลิกได้ และเปลี่ยน Cursor เป็น `not-allowed`

### 2. แผนการแก้ไขสำหรับ Coding Sprint 3 (Future Action Plan)

- **แก้ไข Issue 2:** ขยายขนาดไอคอนถังขยะลบรายการจาก `16px` เป็น `24px` และเปลี่ยนสีเป็นสีแดงเตือน (`#DC2626`) เมื่อ Hover
- **แก้ไข Issue 3:** ปรับปุ่ม "ชำระเงิน" ให้ใช้ Primary Brand Color ที่มีความเข้มสูง พร้อมเพิ่ม Padding และ Shadow ให้โดดเด่นขึ้นเด่นชัดจากส่วนสรุปราคา
