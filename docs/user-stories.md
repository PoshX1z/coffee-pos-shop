### หัวข้อที่ 1 แปลง Functional Requirement To User Story อย่างน้อย 6 เรื่อง และระบุ Acceptance Criteria

## User Story 1

- FR-01 ระบบต้องสามารถให้พนักงานบันทึกรายการสั่งซื้อของลูกค้าได้
- As a: พนักงานแคชเชียร์
- I want: บันทึกรายการสั่งซื้อลูกค้าผ่านระบบ POS
- So that: เพื่อลดความผิดพลาดจากการจดออเดอร์ และส่งออเดอร์ไปบาริสตาทันที

### Acceptance Criteria ของ User Story 1

#### ข้อ 1

- Given พนักงานเลือกเมนูสินค้า
- When กดยืนยันรายการสั่งซื้อ
- Then ระบบต้องบันทึกรายการสั่งซื้อสำเร็จ

#### ข้อ 2

- Given ระบบบันทึกรายการสั่งซื้อสำเร็จ
- When ระบบประมวลผลข้อมูล
- Then ระบบต้องส่งรายการสั่งซื้อไปยังหน้าจอบาริสต้าทันที

## User Story 2

- FR-02 ระบบต้องสามารถคำนวณราคารวมของรายการสั่งซื้อได้อัตโนมัติ
- As a: พนักงานแคชเชียร์
- I want: ให้ระบบคำนวณราคารวมของรายการสั่งซื้อโดยอัตโนมัติ
- So that: เพื่อลดข้อผิดพลาดในการคิดเงิน และเพิ่มความรวดเร็วในการให้บริการ

### Acceptance Criteria ของ User Story 2

#### ข้อ 1

- Given พนักงานเพิ่มสินค้าอย่างน้อย 1 รายการ
- When เพิ่มสินค้าในรายการสั่งซื้อ
- Then ระบบต้องคำนวณราคารวมโดยอัตโนมัติ

#### ข้อ 2

- Given มีการลบสินค้าออกจากรายการสั่งซื้อ
- When ระบบอัปเดตรายการสินค้า
- Then ระบบต้องคำนวณราคารวมใหม่ทันที

## User Story 3

- FR-03 ระบบต้องสามารถรองรับการชำระเงินด้วยเงินสด QR Code และบัตรได้
- As a: พนักงานแคชเชียร์
- I want: รับชำระเงินผ่านระบบ POS ทั้งเงินสด QR Code และบัตร
- So that: เพื่อให้ลูกค้าสามารถชำระเงินได้สะดวก รวดเร็ว และถูกต้อง

### Acceptance Criteria ของ User Story 3

#### ข้อ 1

- Given ลูกค้าเลือกชำระด้วยเงินสด
- When พนักงานรับเงินและยืนยันการชำระ
- Then ระบบต้องบันทึกการรับเงินและคำนวณเงินทอน

#### ข้อ 2

- Given ลูกค้าเลือกชำระผ่าน QR Code หรือบัตร
- When การชำระเงินเสร็จสมบูรณ์
- Then ระบบต้องยืนยันการชำระเงินสำเร็จ

## User Story 4

- FR-04 ระบบต้องสามารถออกใบเสร็จให้ลูกค้าได้
- As a: พนักงานแคชเชียร์
- I want: ออกใบเสร็จให้ลูกค้าหลังจากชำระเงินสำเร็จ
- So that: เพื่อให้ลูกค้าได้รับหลักฐานการชำระเงินที่ถูกต้อง

### Acceptance Criteria ของ User Story 4

#### ข้อ 1

- Given ลูกค้าชำระเงินสำเร็จ
- When ระบบยืนยันการชำระเงิน
- Then ระบบต้องสร้างใบเสร็จโดยอัตโนมัติ

#### ข้อ 2

- Given ระบบสร้างใบเสร็จเรียบร้อย
- When พนักงานเลือกพิมพ์ใบเสร็จ
- Then ระบบต้องพิมพ์ใบเสร็จได้ถูกต้อง

## User Story 5

- FR-05 ระบบต้องสามารถตัดสต็อกสินค้าอัตโนมัติหลังชำระเงินสำเร็จ
- As a: ผู้จัดการร้าน
- I want: ให้ระบบตัดสต็อกสินค้าอัตโนมัติหลังการขาย
- So that: เพื่อให้ข้อมูลสต็อกสินค้าและวัตถุดิบมีความถูกต้องและตรงตามปัจจุบัน

### Acceptance Criteria ของ User Story 5

#### ข้อ 1

- Given ลูกค้าชำระเงินสำเร็จ
- When ระบบบันทึกข้อมูลการขาย
- Then ระบบต้องตัดสต็อกสินค้าโดยอัตโนมัติ

#### ข้อ 2

- Given จำนวนสินค้าคงเหลือต่ำกว่าที่กำหนด
- When ระบบตรวจสอบสต็อก
- Then ระบบต้องแจ้งเตือนผู้จัดการร้าน

## User Story 6

- FR-06 ระบบต้องสามารถแสดงรายงานยอดขายประจำวันได้
- As a: ผู้จัดการร้าน
- I want: ดูรายงานยอดขายผ่านระบบ
- So that: เพื่อตรวจสอบผลการดำเนินงานของร้านและนำข้อมูลไปใช้วางแผนการบริหารร้าน

### Acceptance Criteria ของ User Story 6

#### ข้อ 1

- Given มีข้อมูลการขายในระบบ
- When ผู้จัดการเลือกเมนูรายงานยอดขายประจำวัน
- Then ระบบต้องแสดงข้อมูลยอดขายประจำวันได้ถูกต้อง

#### ข้อ 2

- Given ผู้จัดการเลือกดูรายงานยอดขายประจำเดือน
- When ระบบประมวลผลข้อมูล
- Then ระบบต้องแสดงยอดขายรวมของแต่ละเดือนได้ถูกต้อง

### หัวข้อที่ 2 ระบุ Actor

- 1. ลูกค้า
- 2. พนักงานหน้าร้าน
- 3. บาริสต้า
- 4. ผู้จัดการร้าน
- 5. ผู้ดูแลระบบ
